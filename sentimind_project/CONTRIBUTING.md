# Contribuir a Sentimind

¡Gracias por querer contribuir!

## Flujo recomendado

1. Haz fork del repositorio.
2. Crea una rama para tu cambio (`feature/...` o `fix/...`).
3. Ejecuta el proyecto y valida que funciona.
4. Envía un Pull Request con descripción clara.

## Estándares mínimos

- Mantener cambios enfocados y pequeños.
- No romper `make test` ni `make lint`.
- Documentar cambios relevantes en `README.md` o docs asociadas.

## Comandos útiles

```bash
make dev
make test
make lint
```

## Reporte de issues

Incluye siempre:

- Pasos para reproducir.
- Resultado esperado vs actual.
- Entorno (SO, versión de Docker/Node/Python).
