# Frontend - Sentimind

Aplicación React para autenticación, publicación de posts y visualización de sentimientos detectados.

## Stack

- React 19
- TypeScript
- Vite
- React Router
- Axios

## Ejecutar local

Con Bun:

```bash
bun install
bun run dev
```

Con npm:

```bash
npm install
npm run dev
```

## Scripts disponibles

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

## Variables de entorno

Basarse en:

- `.env.example`

Variable principal:

- `VITE_API_URL` (ejemplo: `http://localhost:8000/api`)
